# 🩺 Medical App Home Screen UI – Jetpack Compose

This project showcases a **static Home Screen UI** for a Medical App built with **Jetpack Compose**. The layout is responsive and follows modern design standards for Android devices.

## ✨ Features

- 📱 **Jetpack Compose UI only**
- 🖼️ Clean and modern design
- ⚡ Responsive layout for all screen sizes
- 🎯 Constraint-based positioning using Modifier/Box/Column/Row
- 🌐 No dynamic data or backend – UI only

## 🔧 Tech Stack

- 💻 Kotlin
- 🧱 Jetpack Compose
- 🎨 Material Design 3

- 🛠️ Android Studio
